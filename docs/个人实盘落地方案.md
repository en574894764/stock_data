## 二、四项必要改造

### 改造 1：TopN 降到 20-30（执行可行性）

- **100 万 → Top30**（每只 ≈3.3 万）；**50 万 → Top20-25**
- 理由：Top50 每只 1-2 万，遇到 100 元以上股票一手就超配/买不起；30 只的分散度对月频足够（个股上限 3.3%，特异风险已被充分稀释）
- 配置改动：`strategy_config.config.top_n: 50 → 30`

### 改造 2：剔除高价股（一手约束）

- 剔除 `close > 150 元` 的股票（或在 generate_signals 股票池过滤加一条 `close*100 <= per_stock_budget*0.9`，保证至少买得起 1 手且不为零头仓）
- 高价股集中在白酒/医药/新能源龙头，剔除对中小盘偏好的组合影响很小

### 改造 3：实现择时层（个人唯一的风控防线）

```python
# strategy_config.config.timing_filter 实现
{"type": "ma200", "index": "000852.SH", "rule": "close < MA200 → 仓位×0.5"}
```

- 中证1000 收盘 < 200 日均线 → 目标仓位降至 50%；收回上方 → 恢复
- 为什么用中证1000 不用沪深300：组合池偏中小盘，β 对手中证1000
- 验证方法：`backtest_ts.py --symbol idx:000852 --strategy trend --window 200` 跑历史，看"减半仓"挡掉多少回撤、错过多少反弹，用数字决定保留与否
- 代价（要诚实）：牛市初期的假信号会踏空 5-10%；这是没有对冲工具的个人必须付的保险费

### 改造 4：对照基准监控（防伪 α）

- 每月调仓日同时记录：组合净值 vs 中证1000ETF（512100）净值
- 连续 3 个月跑输中证1000 → 触发复盘（检查是否小盘风格逆转/因子失效）
- 你 `ln_mv` 因子 Q5 年化 27.4% 是伪 α 活例——α 里掺了小盘 β，对照监控是唯一报警器

## 三、三阶段推进路径

### 阶段 0：模拟盘 3-6 个月（现在就启动，零成本）

- `execute_signals.py --simulate` 已支持（虚拟 100 万），把 pipeline 里这一步从"非阻塞"改为"必跑 + 飞书推送"
- 目的：① 验证信号→执行→净值全链路 ② 实测滑点（模拟用开盘价 vs 实际可成交价的偏差）③ 检验每月换手率和成本假设
- **通过标准**：3 个月无链路事故 + 模拟净值与回测净值偏差 < 2pp/季

### 阶段 1：小仓实盘（10-20 万，2-3 个月）

- 同一策略同一信号，只是仓位小
- 目的：用真钱暴露模拟盘发现不了的问题（滑点、停牌、涨跌停买不进、心理波动）
- **通过标准**：能严格按信号执行 3 期调仓，无一次"我觉得这只更好"式干预

### 阶段 2：目标仓位（50-100 万）+ 持续运维

- 按第五节 SOP 运行，按第六节仓位方案控制总风险
- 每季度重跑 `factor_eval.py` 检查因子衰减，`crowding_monitor` 周度盯拥挤度

## 五、每月操作 SOP（半天）

| 时间 | 动作 | 命令/操作 |
|---|---|---|
| 每日 18:30 | 数据自动更新 | launchd（已有，无需动作）|
| 调仓日 T 晚 | 生成信号 + 飞书推送 | `generate_signals.py --strategy prod_6f_eq --push` |
| T+1 14:30-14:50 | 卖出（先卖腾资金） | 按 SELL 清单限价/对手价分批 |
| T+1 14:50-15:00 | 买入 | 按 BUY 清单，避免开盘半小时波动 |
| T+1 收盘后 | 回填成交 | `execute_signals.py --confirm --signal-id X --price Y` |
| 每月一次 | 对照复盘 | `benchmark_track.py`：组合 vs 中证1000，超/跑输归因 |
| 每季度一次 | 因子体检 | `factor_eval.py --start 2019-01-01`，看 IC 衰减 |

执行纪律（写死）：
- 停牌/一字涨跌停买不进 → 跳过该标的，资金留到下期（不追）
- 卖出遇跌停 → 顺延次日，连续 3 日跌停报人工决策
- **任何"我觉得"式干预 = 违规**，干预一次记录一次，季度复盘时统计

## 六、成本与预期核算（诚实版）

**成本**（月换手约 40%，单边 0.15%）：
- 年化交易成本 ≈ 0.15% × 2 × 40% × 12 ≈ **1.4%/年**
- 硬件/数据成本 ≈ 0（tushare 积分 + akshare 免费）

**预期收益**（对回测打折扣）：

| 项 | 回测值 | 实盘保守预期 | 折扣理由 |
|---|---|---|---|
| α | +18pp/年 | **+10-12pp/年** | 超额行业性收敛（2026 指增均值 4%）；伪 α 剥离；滑点 |
| β | ≈1 × 市场 | ≈1 × 市场 | 不可控 |
| 成本 | -1.5pp | -1.4pp | — |
| **合计** | 24% | **市场 + 8-11pp** | 市场长期 6-8% → 总预期 15-18% |

**回撤预算**：-25% ~ -35%（含择时层可略降）。**50 万本金浮亏到 34 万时你还在按信号执行——这是唯一真正的前提条件。**

**若回撤承受力不足**：50% 策略 + 50% 债基/货基 → 波动减半（-15% 级回撤），预期降到 8-10%。这是完全合法的选项，不是懦弱。

## 七、风险清单（这个方案会死在哪）

1. **小盘风格逆转**（最大风险）：你的 α 一部分是小盘 β。2024 年 1-2 月微盘踩踏已演示过一次。对策：benchmark_track 对照监控 + 择时层
2. **因子集体失效**：行业同质化拥挤，2026 年超额已腰斩。对策：季度 factor_eval + crowding_monitor 周度
3. **执行滑坡**：个人最大的敌人是自己。对策：SOP 纪律条款 + 干预记录
4. **单点故障**：launchd 停跑数据断档。对策：validate.py 已有缺口检查，接到飞书告警（已有）
5. **过拟合怀疑**：回测 24% 是 2019-2026 单一市场单一路径。对策：这就是为什么阶段 0 模拟盘不可跳过
