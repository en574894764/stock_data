# 横截面多因子组合 vs 少数标的择时：路线对比

> 整理日期：2026-09-08
> 背景：本项目（stock_data）当前以因子体系为主线（factor_value 21 因子 + 6 因子等权组合），
> 同时已具备时序回测双引擎（backtest_ts / combo_backtest）。本文梳理两条路线的定位与优劣。

## 一、两条路线是什么

| | 路线 A：横截面多因子 | 路线 B：少数标的择时 |
|---|---|---|
| 回答的问题 | "这一期，几千只里买哪一批" | "这个标的，现在持有还是离场" |
| 典型形态 | 多因子选股、指数增强、风格因子组合 | CTA 趋势跟踪、双动量配置、波动率目标、均线择时 |
| 信号结构 | 截面（cross-sectional）：同一时点比较标的间相对强弱 | 时序（time-series）：单一标的自身历史生成信号 |
| 持仓特征 | 宽持仓（数十~数百只），近似市场中性或轻 beta | 窄持仓（1~10 只），仓位/方向随信号时变 |
| 收益来源 | 个股相对 alpha（理论上可剥离 beta） | beta 的上涨段落 + 危机时的避险离场 |

## 二、是否主流？

**A 是机构量化的绝对主流。** Barra/Axioma 风险模型、AQR、Two Sigma 的因子层、
国内几乎所有指增与量化选股私募，均以横截面多因子为核心。
本项目 factor 体系（IC/分层/组合回测）即其标准个人版实现。

**B 同样是正统流派，但生态位不同。** 海外 CTA 行业（Winton、Man AHL 一系）、
风险平价中的波动率目标层、个人投资者圈的双动量（Antonacci, 2013）都是 B。
机构普遍**叠加使用**：因子组合做核心仓位，CTA/择时做卫星，
因为两类收益（alpha vs trend premium）相关性天然低。

## 三、理论根基的差异：广度定律

Grinold 主动管理基本定律：

```
IR ≈ IC × √N
```

- 路线 A：N = 全市场股票数（A股 ~5000）。IC 只需 1%~2%，
  靠大数定律把微弱的截面预测力堆成可观的信息比率。单票看错无感，错误高度分散。
- 路线 B：N = 3~10 个标的（且非独立）。无法借广度，
  只能靠单点信号质量（高 IC）或低胜率×高盈亏比的结构硬扛。

**这一定律决定了两路线几乎所有下游差异。**

## 四、逐维度对比

| 维度 | A：横截面多因子 | B：少数标的择时 |
|---|---|---|
| 统计可信度 | 高：数千独立观测，过拟合易被识破 | 低：几十次交易，参数微调结果剧变，极易拟合出幻觉 |
| 运气权重 | 低（大数定律平均掉） | 高（无分散，一次错判直接体现在净值） |
| 市场状态依赖 | 弱：牛熊中因子均可能有 alpha（幅度波动） | 强：单边趋势赚翻，长期横盘被反复止损（均线类经典死法） |
| 容量 | 中小资金无虞；超大资金有冲击成本 | 个人小资金反而占优 |
| 交易成本 | 换手高、调仓重、滑点明显 | 月频都可行，摩擦极低 |
| 数据/系统要求 | 重：全市场行情+财务截面、去极值、中性化、防幸存者偏差 | 轻：一根指数日线即可 |
| 可验证性 | 强：IC/分层/多空组合/样本外，评估体系成熟 | 弱：绩效对参数敏感，需要跨市场跨周期稳健性检验兜底 |
| 典型失效模式 | 因子拥挤、风格反转（如 2019-2026 白马还债期 roe/sue_gr 失效）、财务造假 | 横盘市磨损、参数过时、执行纪律崩溃（该止损时不执行） |
| 对执行纪律要求 | 中（组合化、批量化，情绪难干预） | 极高（信号少而关键，每一次都在对抗人性） |

## 五、各自的真实优势

### A 的核心优势：可验证性，而非收益本身
宽截面给出足够统计功效去**证伪**。IC 衰减、分层单调性破坏、拥挤度上升
都能被及时观测到——本项目的 crowding_monitor 就是干这个的。
一个回测好看的因子能不能上车，有一整套裁判体系，而不是靠信仰。

### B 的核心优势：成本与简洁，及危机对冲价值
- 信号少、换手低，一个指数日线就能跑，散户完全可实现；
- 趋势策略在 1987、2008、2015 型危机中普遍赚钱（避险离场本身是收益），
  与因子组合回撤期恰好错开；
- 不依赖财务数据，没有财报造假、幸存者偏差那类坑。

### B 的补救手段：换维度分散
截面广度借不到，就在**品种 × 周期**上分散：
跨股票/债券/商品/黄金多市场 + 长短两套周期信号。
CTA 行业靠此存活数十年。反例：只对一两个指数用单一均线择时，
是 B 路线里统计上最脆弱的形态（本项目双引擎若用于择时，应避免此形态）。

## 六、A 股环境的特殊性

| 视角 | 对 A | 对 B |
|---|---|---|
| 散户占比高 | 截面异象（反转/低波/SUE）比美股显著且衰减慢——本项目实证：技术指标因子 IC 2.6~4.2% 全弱于原生因子，ret_20d_rev/ivol_60 显著 | 情绪驱动的单边行情多，趋势段明确 |
| 指数长期宽幅横盘 | 影响小（赚相对强弱） | 致命伤：2010-2014、2021-2024 型横盘期反复止损 |
| 做空受限 | 多头alpha为主，beta敞口难完全对冲（可用股指期货/融券部分解决） | 影响小（择时可空仓即避险） |

两条路线的强弱周期恰好错开——这是"叠加"的本土依据。

## 七、与本项目体系的映射

| 路线 | 已有组件 | 缺口 |
|---|---|---|
| A | factor_value（21 因子，2.8 亿行）、factor_eval（IC/IR/分层/三模式组合）、6 因子等权组合（Q5 年化 ~22%，样本外 2023-2026 夏普 1.06）、crowding_monitor | 基本完备 |
| B | backtest_ts（vectorbt，5 内置策略，三源路由）、combo_backtest（多策略×多标的，贡献/相关矩阵） | **分散度**：需从单指数择时升级为 ETF 池（股票/债券/黄金/商品 8~10 只）动量轮动 |

## 八、建议：叠加而非二选一

1. **核心仓位（A）**：6 因子等权组合，维持现有监控（IC 衰减 + 拥挤度）。
2. **卫星仓位（B）**：ETF 池 dual momentum——
   绝对动量过滤（12 期动量为负则切现金/债券）+ 相对动量选 top1-2，
   月频再平衡，摩擦极低。
3. **验证**：用 combo_backtest 跑"因子组合 + ETF 动量"的日度收益相关矩阵，
   确认相关性足够低（< 0.3 量级）后看叠加净值的回撤改善。
