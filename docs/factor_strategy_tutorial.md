## 一、心智模型：多因子策略的完整生产链

### 1.1 一张地图

机构级多因子体系是六个环节的闭环，不是一条直线：

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  ① 因子挖掘 ──→ ② 因子检验 ──→ ③ 因子合成              │
│      ↑                                    ↓             │
│      │                                ④ 组合构建          │
│  ⑥ 复盘迭代 ←── ⑤ 执行与监控 ←──────────┘              │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

东方基金王怀勋的拆解最简洁：**因子挖掘 → 因子合成 → 组合构建**三大环节。华泰金工的三环节与之同构（因子生成 / 多因子合成 / 组合优化与风控）。第六个环节（复盘迭代）是散户和机构真正的分水岭——机构有专人每天做，散户大多只做前三步然后祈祷。

**本项目现状**：①②已完成（21 因子入库，IC/IR/分层检验框架可复跑）；③已完成实证（等权 vs IC 加权 vs 正交化三模式对照）；④⑤⑥未建——这正是本教程后两章要解决的。

### 1.2 Alpha 模型与风险模型：两条腿

机构框架下，多因子模型分两半：

- **Alpha 模型**（预测收益）：因子值 → 预期超额收益。我们做的 IC/IR 检验、因子合成全部属于这条腿。
- **风险模型**（控制波动）：Barra 式分解，把股票收益拆成 市场联动 + 行业 + 风格 + 特异，预测组合的主动风险。

王怀勋的原话值得记住：**"风险模型的构建往往比 Alpha 模型更决定最终业绩稳定性"**。散户视角的翻译：选股选得再好，如果组合 60% 都是同一风格（比如全押小市值），一次风格切换就打回原形。我们的 6 因子组合目前只有风险模型的雏形（因子相关性矩阵 + 拥挤度监控），没有正式的行业/风格中性化。

### 1.3 两条铁律（先记住，第三章展开）

1. **回测是假设检验，不是业绩承诺**。每次调参数都是消耗一次统计可信度。
2. **因子失效只是时间问题**（王怀勋："我们统计的规律只能叫异象——是表象而非实质"）。所以复盘不是可选项，是系统的呼吸。

## 二、从因子到策略

### 2.1 因子预处理（合成之前必须做）

机构标准流水线是三步：**去极值 → 标准化 → 中性化**。

| 步骤 | 方法 | 目的 | 本项目现状 |
|---|---|---|---|
| 去极值 | MAD 法（中位数绝对偏差 ×5）或 3σ 截尾 | 防极端值主导截面回归/z-score | 未做（z-score 对极值敏感，待补） |
| 标准化 | 截面 z-score | 消除量纲，因子可加 | ✅ factor_eval 合成时做了 |
| 中性化 | 对行业哑变量 + 市值回归取残差 | 剥离风格暴露，得到"纯净 alpha" | **未做，最大的待补项** |

**中性化为什么关键**：我们的 ln_mv（小市值）因子天然扎堆在特定行业；不中性化，组合等于隐性押注行业轮动。华泰的做法是五因子中性化（行业、市值、20日收益率、20日波动率、20日换手率），其 AI 量价因子中性化后 RankIC 8.87%、IC_IR 1.16——注意因子本身没变，变的只是"纯净度"。

**决策点**：中性化会牺牲收益（行业暴露本身有收益，尤其小市值周期），换来归因干净。要"选股的钱"还是接受"选股+风格的钱"，这是投资观问题，不是技术问题。

### 2.2 因子合成：五种方法与我们的实证结论

| 方法 | 原理 | 优点 | 缺点 | 本项目实证（2019-2026） |
|---|---|---|---|---|
| 等权 | z-score 直接平均 | 简单、稳健、不怕 IC 估计噪声 | 忽略因子强弱差异 | Q5 年化 **20.4%**（8因子） |
| IC 加权 | 滚动 IC 均值为权重 | 自适应因子强弱 | 高相关强因子吃掉全部权重 | 18.4%（**跑输等权**） |
| ICIR 加权 | IC均值/IC标准差为权重 | 兼顾强度与稳定性 | 同样的冗余集中问题 | 未单独测（与 IC 加权同病） |
| 回归法 | 截面回归求因子溢价 | 理论最优（似然框架） | 对共线性敏感，估计噪声大 | 未做 |
| 机器学习 | XGBoost/NN 端到端 | 非线性、高维 | 过拟合风险、黑箱 | 未做（21 因子线性信息已够用） |

**我们的关键实证发现**（写进 memory 的教训）：IC 加权跑输等权 2 个点，因为 turnover_20 和 ivol_60 互相关 0.92，IC 加权给它们合计 52% 权重——**加权不处理冗余，正交化才处理**。正交化等权（滚动 IC 降序 → 截面回归残差化）与等权打平但 IC 正率更高（76.7% vs 71.4%）。

**给独立投资者的建议**：从等权开始。因子少于 10 个、且已做过相关性去重时，等权几乎不可能被复杂方法显著打败。这是学术界（DeMiguel 等人 "1/N" 论文）和我们的实证共同支持的结论。

### 2.3 选股规则：从综合分到买入名单

三种范式（激进程度递增）：

| 方法 | 规则 | 特点 | 适用 |
|---|---|---|---|
| 分位法 | 买前 20% | 回测口径，分散 | 基准参考 |
| Top-N | 综合分最高的 N 只 | 集中度可控 | **推荐主力方案** |
| 阈值法 | 分数 > 阈值才买，不满则空仓 | 自带择时 | 想躲熊市的人 |

比"选哪个"更重要的是**过滤清单**（每条都是实盘教训）：

```
□ 非 ST/*ST/退市整理期          （本项目已做）
□ 上市 ≥ 120 自然日              （本项目已做，次新波动大）
□ 日均成交额 ≥ 3000 万           （待做——容量底线，买不进卖不出等于零）
□ 当日非涨停                     （待做——涨停买不进，信号失真）
□ 非停牌/非长期停牌复牌首日      （待做）
□ 财务红旗过滤                   （待做——审计非标意见等，financial 数据库有原料）
□ 剔除超高价股（如 >500 元）     （可选——一手 10 万+ 仓位粒度太粗）
```

### 2.4 组合构建：权重设计

从简单到复杂：

1. **等权**：每只 1/N。对小资金（百万级以内）几乎总是够用。
2. **得分线性加权**：weight ∝ 综合分排名。锐度略升，复杂度微升。
3. **风险平价**：按 1/波动率 配权（低波多配）。我们已有 ivol 数据，一行代码的事。
4. **均值方差优化（Markowitz）**：需要协方差矩阵估计。**警告**：样本协方差在股票数 > 观测期数时病态，估计误差被优化器放大——"误差最大化器"。机构用 Barra 结构化协方差（因子协方差 + 特异风险分层估计）绕开这个问题。独立投资者不建议碰。

机构实际的优化器约束（参考华泰 AI 中证 1000 增强的真实参数）：

- 成分股权重 ≥ 80%（跟踪基准）
- 个股权重偏离上限 0.8%
- Barra 风格暴露 < 0.3
- 周双边换手率 ≤ 30%

独立投资者不需要这么多约束，**个股上限 3-5% + 行业上限 20-25% + 换手率监控**三条足矣。

### 2.5 调仓设计：频率与缓冲区

**频率与信号衰减匹配**（核心原理）：

| 因子类型 | 半衰期 | 合适频率 |
|---|---|---|
| 短期反转（ret_20d_rev） | 2-4 周 | 周度~双周 |
| 换手率/波动率 | 1-3 月 | 月度 |
| 估值（ep_ttm） | 6-12 月 | 季度 |
| 成长/质量 | 6-12 月 | 季度 |

我们 6 因子混合了快慢信号，**月度调仓是成本与衰减的折中**；想榨反转因子的衰减收益可上双周，代价是换手率翻倍。

**缓冲区（hysteresis）——成本控制的生命线**：

> 老持仓跌出 Top 50 不马上卖，跌出 Top 100（缓冲带）才卖；空出的额度买入当前 Top 50。

没有缓冲区的月度 Top 50 组合，年双边换手轻松 600%+。按单边 0.15% 算，成本一年吃掉 1.8% 年化收益。有缓冲区能砍一半以上，而收益几乎不变——因为卖掉的本来就是要掉出名单的边际股。

### 2.6 择时叠加（可选层）

因子体系是"永远满仓的选股引擎"；择时层决定"什么时候降仓"。三种由粗到细：

1. **趋势过滤**：沪深300 收于 200 日均线下方 → 总仓位降至 50-60%。规则简单，历史上能把最大回撤从 -28% 压到 -15% 量级；代价是震荡市反复止损。
2. **拥挤度调节**（本项目已有数据）：`crowding_monitor` 显示某因子拥挤度分位 > 90% → 该因子权重减半。这是**因子层择时**，比大盘择时精细，且有学术依据（风格拥挤是动量崩溃的主因之一）。当前读数：turnover_20 分位 87%、ivol_60 83%，已在升温区。
3. **波动率目标**：组合实现波动率 > 25% 年化 → 等比降仓。纯风控逻辑，不预测方向。

**建议**：1 + 2 组合。大盘趋势定仓位上限，拥挤度定因子权重。两者都只依赖已入库数据。

### 2.7 A 股执行现实（不做这些，回测全是幻觉）

| 规则 | 对策略的约束 |
|---|---|
| T+1 制度 | 今天买明天才能卖 → 日频止损不可能，只能靠分散 |
| 涨跌停 | 涨停买不进、跌停卖不出 → 选股日剔除涨停股；回测按"能成交"假设会高估 |
| 一手 100 股 | 高价股仓位粒度粗 → 组合数量少时权重偏离等权 |
| 印花税 | 卖出 0.05%（2023 年 8 月减半后）→ 成本建模必须含 |
| 冲击成本 | 小盘股大单买入推高价格 → 成交额过滤线越高越安全 |

## 三、回测方法论

### 3.1 回测的本质

Lopez de Prado 的警告：**回测不是实验，是历史数据的假设检验**。金融数据无法重复实验（王怀勋的"守株待兔"），历史样本也不代表当前市场（"刻舟求剑"）。每个回测结论的保质期有限，所以需要持续复盘来验证规律是否还活着。

### 3.2 七大偏差：每条配本项目的防线

| # | 偏差 | 定义 | 本项目防线 | 状态 |
|---|---|---|---|---|
| 1 | **幸存者偏差** | 只测活到今天的股票 | daily_basic/daily_quote 含退市股（踩过 3 次的 KeyError 坑反而是证据——退市股真的在库里） | ✅ 数据层已防 |
| 2 | **前视偏差** | 用了当时不可能知道的信息 | 财报因子全部 PIT 对齐（ann_date ≤ T）；信号 T 日算、T+1 执行 | ✅ 代码层已防 |
| 3 | **数据窥探** | 试了 N 个策略只报告最好的 | 6 因子是检验后选的，样本外 2023-2026 分段验证未失真 | ⚠️ 部分——试验次数没有正式记账 |
| 4 | **过拟合** | 参数记住噪声 | 策略规则少（等权、月度、Top-N）；正交化超参只用 1 个（12 期 IC 窗口） | ✅ 结构简单 |
| 5 | **成本忽略** | 无摩擦假设 | 单边 0.15% 含滑点；月调仓换手低 | ✅ |
| 6 | **离群值敏感** | 单一事件（如 2015 股灾）撑起全部收益 | 8 年回测跨牛熊；未做逐年拆解 | ⚠️ 待做年度分拆 |
| 7 | **非平稳性** | 规律随市场结构改变 | roe_lf 失效就是活例子（2019-2026 白马还债）；滚动 IC 监控是解药 | ✅ 框架已有 |

### 3.3 检验体系（本项目 factor_eval 的实际做法）

**第一层：IC 检验**（因子与下期收益的截面秩相关）

- IC 均值 > 0.03：基本有效
- IR（IC均值/IC标准差）> 0.5：稳定可用
- IC 正率 > 55%：方向一致性好

我们的实证参考系：ret_20d_rev 8.6%/0.56/69% 是强因子标准线；rsi_14 4.2%/0.30/57% 是"指标类天花板"。

**第二层：分层回测**（五分组净值的单调性）

不单调的因子不能用——Q3 比 Q5 高说明因子关系非线性或紊乱。看 Q1→Q5 是否阶梯上升 + 多空组年化差。

**第三层：组合回测**（含成本的净值模拟）

要点全部在细节里：T 日信号 → T+1 收盘建仓（用 T+1 到 T+21 的前向收益）、等权、单边成本按日摊销、停牌股自动跳过。

**第四层：样本内外分段**（最重要也最常被跳过）

- 样本内（2019-2022）：检验"选出来的规律在这段成立"——这只是及格线
- 样本外（2023-2026）：检验"规律在没见过的数据上还成立"——这才是付费环节

我们的结果：6 因子等权样本内 20.0%、样本外 24.0%，夏普 1.01 → 1.06。**样本外不衰反升**是规律真实性的强证据（也可能含小市值风格 2023 后走强的 beta 成分——归因见第四章）。

### 3.4 统计加固：防止自己骗自己

进阶工具，独立投资者按需取用：

- **Deflated Sharpe Ratio（DSR）**：报告夏普前先问"试了多少个策略"。试 100 个，随机策略里最好的夏普也能到 1.5。DSR 把试验次数 N 作为惩罚项。经验法则：**全程试验 < 10 次且样本外夏普 > 1**，可信度尚可。
- **PBO（回测过拟合概率）**：组合式交叉验证算"样本内最优策略在样本外跑输中位数"的概率。PBO > 0.5 = 大概率过拟合。
- **Walk-forward**：滚动窗口重训重测，拼接样本外净值。我们的滚动 IC 加权本质上是简化版 walk-forward。
- **试验日志**：最朴素也最有效——每次回测记一行（日期/假设/参数/结果）。三个月后回看，你会惊讶自己试了多少次。

### 3.5 成本建模数学

年化成本拖累 = 年双边换手率 × 单边成本。

| 换手水平 | 年双边换手 | 单边 0.15% 时年成本 |
|---|---|---|
| 月度 Top50 无缓冲 | ~600% | 1.8% |
| 月度 Top50 有缓冲 | ~250% | 0.75% |
| 双周 有缓冲 | ~400% | 1.2% |
| 季度调仓 | ~100% | 0.3% |

单边 0.15% 的构成：佣金 0.025%（万一免五已绝迹，按万 2.5）+ 印花税 0.05%（卖出）+ 滑点 ~0.05% + 冲击 ~0.03%。小资金百万内基本就是这个量级。

### 3.6 回测报告 checklist

一份诚实的回测报告应包含（自查表）：

```
□ 样本区间 + 为什么选这个区间（包含至少一轮完整牛熊）
□ 样本内/外分段结果 + 分年度收益
□ 交易成本假设的具体构成
□ 换手率（年双边）与容量估计
□ 最大回撤发生的时间点 + 当时发生了什么
□ 参数敏感性：调仓日 ±3 天、Top-N ±20 只，结果稳不稳
□ 与基准的对比（沪深300 全收益，不是价格指数）
□ 已知的偏差残留声明（哪些没防住）
□ 试验次数记录
```

## 四、每日复盘体系

### 4.1 复盘的目标：区分运气、能力、环境

每天收盘后问三个问题：

1. 今天赚/亏的钱，是**因子该赚的**（信号兑现）还是**风格给的**（beta 顺风）还是**随机噪声**？
2. 因子还健康吗（滚动 IC 还在吗）？
3. 环境变了吗（拥挤度、风格切换、市场结构）？

米筐的归因框架给了第一刀：**交易收益 vs 持仓收益**。交易收益是成交价与日终价的差（执行能力），持仓收益是日终价格变动（决策能力）。独立投资者做量化，执行端不该贡献收益——如果交易收益显著为正或为负，说明执行时机有系统性问题。

### 4.2 三层归因框架

**第一层：基础收益拆解**（每天，5 分钟）

- 当日组合收益 vs 基准收益（超额）
- 交易收益 vs 持仓收益
- 前 5 贡献股 / 前 5 拖累股（肉眼检查有没有异常）

**第二层：归因分解**（每周，30 分钟）

两条技术路线，按数据可得性选：

- **Brinson 归因**（基于持仓）：超额收益 = 配置收益 + 选股收益。BF 版本（无交互项）+ GRAP 算法（多期再投资修正）是华泰实证推荐的实现。适合回答"我跑赢是因为行业押对了还是行业内选对了股"。
- **因子归因**（基于风险模型，米筐 X-Sigma-Rho 框架）：主动收益 = Σ(因子主动暴露 × 因子收益) + 特异收益。适合回答"我的超额来自小市值暴露还是反转因子还是纯选股 alpha"。

对量化因子组合，**因子归因比 Brinson 更对症**——因为我们本来就知道持仓是怎么选出来的，Brinson 的"配置 vs 选股"二分法对我们是废话，因子暴露才是我们的语言。

简化版做法（无需完整 Barra）：把组合日收益对 6 个因子的多空组合收益回归，系数就是暴露，系数×因子收益就是贡献。我们库里现成有全部原料。

**第三层：信号健康度监控**（每周，10 分钟，数据已全）

| 监控项 | 指标 | 阈值 | 数据来源 |
|---|---|---|---|
| 因子有效性 | 滚动 12 期 IC 均值 | 连续 3 期 < 0 → 降权观察 | factor_value + factor_eval |
| 因子拥挤 | 拥挤度分位 | > 90% 红 / > 70% 黄 | ✅ crowding_monitor 每日刷新 |
| 风格切换 | 因子动量 60d 分位 | 剧烈反转 → 检查 | ✅ crowding_monitor |
| 换手偏差 | 实际 vs 回测假设 | 偏差 > 50% → 成本模型失真 | 交易记录 |
| 跟踪偏离 | 实际持仓 vs 信号名单 | 漂移 > 10% → 执行纪律问题 | 信号输出 vs 成交记录 |

### 4.3 节奏表：日 / 周 / 月 / 季

**每日（收盘后，10-15 分钟）**

```
□ 数据到位检查（pipeline 日志全绿）
□ 当日净值/超额（组合 vs 沪深300）
□ 前 5 贡献/拖累个股，有无异常（停牌/跌停/公告）
□ 拥挤度日报扫一眼（红黄灯变化）
□ 明日信号预览（如有调仓，检查过滤条件命中情况）
```

**每周（周末，30-60 分钟）**

```
□ 滚动 IC 更新（factor_eval 快速跑）
□ 因子归因回归（超额来源分解）
□ 换手率统计 vs 成本假设
□ 飞书周报（本项目 report_builder 可扩展）
```

**每月（月末，1-2 小时）**

```
□ 完整回测对账：模拟净值 vs 实际净值，偏差 > 1% 找原因
□ 调仓执行：信号生成 → 过滤 → 名单 → 次日执行
□ 分月归因报告（Brinson 或因子归因）
```

**每季（季报后，半天）**

```
□ 因子全量重检（财报因子更新后重跑 factor_eval）
□ 因子退役评审：失效因子（如 roe_lf）是否剔除、候选因子是否引入
□ 参数年检：调仓频率、缓冲区宽度、过滤线
□ 容量与资金量复核
```

### 4.4 因子退役流程（本项目的活案例）

roe_lf 的 IC 从历史正走到 2019-2026 的 -0.8%，就是完整的退役剧本：

1. **检测**：滚动 IC 连续转负（不是单期，是趋势）
2. **归因**：为什么失效？——高 ROE 白马风格 2021 后持续还债（宁德时代们从 70x PE 回归）。是环境变了还是规律死了？
3. **决策**：降权 → 观察 → 退役。不直接删除（因子有周期，roe_lf 在 2017-2020 是强因子，未来风格回归可能复活）
4. **留档**：退役原因写进 memory，避免未来无记忆地重新引入

**重要纪律：退役决策不能频繁做**。因子短期失效是常态（IC 的 30% 分位就很难看），每次失效就调仓因子集 = 在因子层面追涨杀跌。季度评审 + 连续 3 期恶化才动手。

### 4.5 复盘 → 迭代的闭环

王怀勋说 AI 时代量化最稀缺的是"点子"（认知）。复盘就是点子的生产线：

```
复盘发现异常 → 形成假设（"小市值因子的超额可能来自打新配售底仓需求"）
→ 小实验验证（分层市值段收益拆解）→ 结论入库（memory/skill）
→ 或进入因子挖掘队列（新因子候选）
```

**闭环的关键是记录**。本项目已有的基础设施：memory 日志（跨会话）、factor_eval 报告（可复跑）、crowding_monitor（每日快照）。缺的是：**信号日志**（每天的组合名单与得分快照，回测对账的依据）——列入第五章待建。

## 六、附录：术语表与参考资料

### 术语表

| 术语 | 释义 |
|---|---|
| IC | 信息系数，因子值与下期收益的截面相关（秩相关 = RankIC），衡量预测能力 |
| IR | IC 均值 / IC 标准差，衡量预测稳定性（组合语境下指年化收益/年化波动） |
| PIT | Point-in-Time，只用当时已公开的数据（财报用公告日对齐而非报告期） |
| 中性化 | 因子对行业/市值等变量回归取残差，剥离风格暴露 |
| 正交化 | 因子间截面回归取残差，消除互相冗余的信息 |
| Brinson 归因 | 超额收益分解为配置收益 + 选股收益的经典模型 |
| DSR | Deflated Sharpe Ratio，按试验次数惩罚后的夏普比率 |
| PBO | 回测过拟合概率，> 0.5 表示大概率过拟合 |
| Walk-forward | 滚动窗口的样本外检验，拼接测试段净值 |
| 缓冲区 | 调仓时的滞后规则（跌出买入区不立即卖，跌出缓冲带才卖） |
| 拥挤度 | 因子多头持仓被市场集中追捧的程度，是动量崩溃的前瞻信号 |
| GRAP | 多期 Brinson 的再投资收益归属算法（归因到超额产生阶段） |
