### 破案 9/1 晚 pipeline push 失败根因
- 不是 push 失败，是 **`git commit` 超时 120s**（TimeoutExpired 杀进程）
- commit 对象实际已写完（本地有 f526fd082），但后续 pull/push 没执行
- 根因：launchd `ProcessType=Background` 调度优先级把 git 拖慢 10~30 倍（手动 4s 的 commit 在 launchd 下 120s+）

### 修复（双管齐下）
1. pipeline.py step_backup 所有 git timeout 统一放大：status 10→60s，commit 120→600s（加 returncode 检查），pull 120→300s，push 180→600s
2. launchd plist `ProcessType: Background → Utility`（更高调度优先级），unload/load 重载生效
