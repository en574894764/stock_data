## 经验沉淀（写到 MEMORY.md）

### pipeline step_backup 设计要点
- launchd Background 进程下 git 操作 timeout 必须给大余量（实测 13s，留 600s 防 IO/CPU 抖动）
- 各步骤必须检查 returncode，否则一次失败会让整个备份"静默丢失"
- index.lock 残留是上次 timeout 的特征，清掉即可（确认无 git 进程后）

### 港股 akshare 源特性（重要！避免误诊）
- 部分港股标的 akshare 长时间（数天到数月）无更新
- 判断方法：手动 `ak.stock_hk_daily(symbol=ts_code)` 看 max(date)
- 应对：missing 报告里港股 stale 数量是预期波动，不必每次都触发全量补数
- 已知 stale 类别：
  ① 小盘股/低流动性 akshare 源不覆盖（占大头）
  ② 港交所休市（节假日）
  ③ 真停牌/退市
  ④ fetch_and_backup 拉取失败（极少，failure_count=0 已修复）
