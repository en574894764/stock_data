## factor_eval 优化收尾 + off-by-one bug 破案 (04:00-04:40)
- **微差根因（戏剧性反转）**: 旧逐日版才有 bug —— navs 列表初始 [1.0] 与 nav_dates 错位 1，DataFrame 构造时初始值占住首日 → 净值序列滞后一天 + 末日收益丢失（7.7 年年化偏差 0.1-0.4pp）。向量化新版（blocks 无初始值）才是正确语义

- 前两轮假设（keep 过滤语义、rank first 列序）均被证伪，白改两轮；教训：**先做最小 A/B 隔离再改代码假设**
