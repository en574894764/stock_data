### filter-repo 踩坑
1. 第一次失败（EOFError）会在 `.git/filter-repo/` 留下 `already_ran` 标记 → 第二次跑被 sanity check 拦截（交互确认 EOF）→ **失败后必须 `rm -rf .git/filter-repo` 再重跑**
2. filter-repo 默认移除 origin remote → 事后 `git remote add origin <url>` 重加
3. 工作区必须干净（未提交变更会触发交互确认 EOF 挂掉）
4. `git bundle create` 相对路径陷阱：bundle 落在 shell cwd 而非仓库根——用绝对路径指定输出

- pipeline step_backup 的 git pull --rebase 在 force push 后首次可能提示 diverge——若 push 失败重试 3 次仍失败需手动处理
