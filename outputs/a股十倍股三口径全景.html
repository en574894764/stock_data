① 窗口越短，十倍越稀缺（0.41% → 0.75% → 12.5%），因为隐含年化从 58.5% 降到 12.9%；

④ 过山车率随窗口上升（49%→56%→67%）：曾达 10x 的股票，时间越长越大概率还回去；
⑤ 唯一全口径不变式：盈利倍数扛全部涨幅（+8.5x / +21.5x / +22.3x），以及——便宜与十倍股在三个口径全部负相关或零相关。

特征小结

  • 起点画像「中间化」：PE 30（分位 44）/ PB 2.05≈市场 / ROE 6.7%（分位 59）/ 市值分位 43——没有任何极端特征
  • 行业：56 个行业，前九名各 6-9 只（电气设备、通信、制药、家电、白酒、航空、黄金、煤炭、半导体）
  • 盈利：净利 +22.3x；格力 +57x、浪潮 +288x
  • 兑现：多轮牛熊接力（2015 年一年兑现 51 只）；中位等待 6-8 年
  • 过山车：336/504 = 67% 的曾达者没守住（万科 16.1x→2.2x）

伍共同特征：三口径交叉验证

四条跨口径铁律

铁律① 盈利增长是唯一硬驱动

  • 净利倍数中位：五年 +8.5x → 十年 +21.5x → 二十年 +22.3x
  • 三口径估值端贡献都接近零或为负（中际旭创 PE 183→53）
  • 十倍股的本质 = 盈利十倍，股价只是会计

铁律② 「便宜」与十倍股彻底绝缘

  • 便宜派（PE<20&PB<2）精度：五年 0.00%、十年 0.00%、二十年 8.0%（低于随机 12.4%）
  • 三口径、六次测试、零命中——统计上这是「负选股」
  • 但便宜股组合亏钱吗？不——它只是与十倍股无关（防守有效、进攻无效，与价值因子报告一致）

铁律③ 起点估值「不便宜」是必要非充分条件

  • 起点 PE 分位：五年 66 / 十年 62 / 二十年 44——没有一个口径的十倍股起点是「市场最便宜的一半」
  • 短窗口（5/10 年）贵得更多：赌产业趋势的资本已经把预期定价进去了
  • 长窗口（20 年）起点平庸化：因为它们的 10x 来自多轮周期，而非起点定价

铁律④ 窗口越短，起点质量信号越失效

  • 起点 ROE 分位：五年 30（差于市场）/ 十年 76 / 二十年 59
  • 五年十倍股起点 1/3 是亏损股——买的是「利润从 0 到 1」，静态报表无从判断
  • 时间越长，「持续的高 ROE」越能沉淀为复利（二十年组的 ROE 分位 59 来自「后来变好」而非「起点就好」）

柒方法论：按口径分别给答案

五年十倍（年化 58.5%）：产业趋势的即期押注

  • 唯一路径：押中一轮正在爆发的超级产业（本轮 = AI 算力：18 只里约 13 只）
  • 静态财务完全无用：所有质量/估值规则精度为零——起点看「订单、产能、产业渗透率」这类报表外的信息
  • 可行做法：①产业趋势定位（算力资本开支、技术渗透曲线）；②产业链宽筛（不选个股，买链条 15-30 只）；③追涨确认（东吴复盘：涨 50% 后成为十倍股概率从 2%→22%，5x→10x 概率 43%）
  • 代价：0.41% 命中率 + 三年蛰伏期；组合化是唯一风险控制手段

十年十倍（年化 26%）：趋势 + 质量的接力

  • 产业趋势仍是主因（电子硬件 60%），但「质量+成长」开始有信号（3.5 倍随机）
  • 可行做法：①在产业趋势内用 ROE>10%&增速>20% 做质量门限（漏掉牧原式个例但提升期望）；②小市值内选择（9/20 起点市值<100 亿）；③接受起点贵（PE 分位 62），用「盈利消化估值」的框架验证（EPS 增速 >> PE 降幅）
  • 兑现耐心：13/20 在第 8-10 年才达成；前半程收益贡献极低

二十年十倍（年化 12.9%）：时间 × 存活 × 卖出纪律

  • 概率高达 12.5%（八年一遇）——比选股更重要的是仓位和耐心：中位等 6-8 年、中途必有 -50% 级回撤
  • 可行做法：①质量门限宽筛做底仓（ROE>10%&增速>20%，精度 18% = 1.5 倍随机，组合 30-50 只）；②每年检视持仓行业是否踩在当轮趋势（家电→白酒→黄金→AI 的接力）；③卖出 = 证伪（产业逻辑终结如万科，才卖）
  • 关键纪律：67% 的曾达者还回去了——牛市后段对「曾达 5x+」的持仓部分止盈，是对幂律最现实的妥协

统一框架（六层体系，三口径通用）

  • 1. 产业趋势定位（β 之源）：五年的 AI、十年的电子、二十年的多轮接力——没有产业趋势就没有十倍
  • 2. 宽筛组合：承认静态精度上限（5 年 0%、10 年 3-8 倍随机、20 年 1.5 倍），用组合赔率替代个股确定性
  • 3. 追涨确认：涨 50% 后概率跃升数倍——放弃「从 1x 买满 10x」的执念
  • 4. 等得起：仓位设计必须让人扛得过 3 年蛰伏 / -50% 回撤
  • 5. 拿住吃幂律：剔掉最高 3 周收益减半——下车成本极高
  • 6. 卖出 = 证伪 + 泡沫兑现：产业终结才清仓；牛市后段部分止盈
与既有体系的衔接：价值因子（双门限 6.3%/夏普 0.36）与 prod_lgbm_neu 负责底仓与防守；十倍股体系是进攻端的「产业趋势卫星仓」。两者按 80/20 或 70/30 混合，风险预算内追求幂律尾部。
